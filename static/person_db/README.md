# Suspect / Reference Database Directory

## Overview
This directory is designated for local reference portrait photographs and suspect database images used by the **ThirdEye Face Recognition & Verification Engine**.

## Usage & Local Setup
During local development or testing:
1. Place frontal portrait photographs of subjects in this directory (supported formats: `.jpg`, `.jpeg`, `.png`).
2. Register subjects through the ThirdEye Admin Dashboard or application interface, which computes and stores 128-dimensional biometric facial encodings in the local database.

## Public Repository Notice & Data Privacy
- **No Private Data:** Actual reference photographs, biometric encodings, and personal identity records are excluded from the public GitHub repository to respect privacy and copyright guidelines.
- **Local Testing:** Users and contributors should supply appropriately licensed or synthetic portrait photographs for local testing.
- **Supported Formats:** RGB / Grayscale frontal face portraits centered with minimal occlusion.
